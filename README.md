# Домашнее задание к работе 4

## Условие задачи

В игре три героя (**A, B, C**) атакуют босса. Их специальная способность **«Тройной удар»** активируется только в том случае, если уровень силы **каждого из трёх героев кратен трём**.

---

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало.**
2. Задать начальное здоровье босса: `healboss = 1000`.
3. Объявить переменные `A`, `B`, `C`.
4. **Ввести** уровень силы первого героя `A`.
5. **Ввести** уровень силы второго героя `B`.
6. **Ввести** уровень силы третьего героя `C`.
7. Проверить, являются ли все три уровня силы кратными трём:

   **(A % 3 == 0) && (B % 3 == 0) && (C % 3 == 0)**

8. Если условие выполняется:
   - активировать способность **«Тройной удар»**;
   - вычислить нанесённый урон: **(A + B + C) × 3**;
   - уменьшить здоровье босса на полученный урон;
   - вывести количество потерянного здоровья и текущее здоровье босса.
9. Если условие не выполняется:
   - нанести обычный урон: **A + B + C**;
   - уменьшить здоровье босса на полученный урон;
   - вывести текущее здоровье босса.
10. **Конец.**
